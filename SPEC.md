# Посылка — V1

Согласовано в чате: GitHub Pages, приложение на главном экране iPhone, облачные проверки WB без Codex, Web Push и история в Google Таблице.

Один владелец, один заказ. Статическая PWA в public/, Worker и последовательный Durable Object в src/, проверки node:test в test/. Секрет WB хранится только как Cloudflare secret. В приложении вводится отдельный случайный ключ доступа к трекеру, который не позволяет обращаться к WB напрямую.

Проверки каждые 15 минут. Первое чтение сохраняет историю без уведомления. Повторы не создают новое событие. Ошибка WB не затирает историю. Время — Europe/Moscow, исходные наносекунды сохраняются точно. Push-подписки разрешены только для известных push-сервисов, отправка с запретом перенаправлений. Интерфейс не выводит секреты или идентификаторы пользователя WB.

Этапы: проверяемая нормализация и сравнение → облачный опрос и push → PWA → браузерная проверка → публикация после наличия аккаунта Cloudflare и нового токена. Старую задачу Codex не отключать до реальной проверки облака и push на iPhone.

Команды: npm ci --ignore-scripts; npm test; npm run check; npm run dev; npm run deploy. Новые сторонние скрипты установки отключены. Тесты покрывают потерю точности, ошибки WB, отсутствие повторов, SSRF и аутентификацию. В UI нативный JS/CSS, без сборщика и UI-зависимостей.

Успех: статус получен из облака, событие записано в таблицу, push получен на установленной PWA. Непроверенные внешние шаги не выдавать за выполненные. Не входит: несколько аккаунтов, автоматическое обновление токена WB, магазин приложений.
